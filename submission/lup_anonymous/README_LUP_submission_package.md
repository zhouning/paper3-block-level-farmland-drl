# Anonymous Land Use Policy Review Package - Paper 3

This directory contains the anonymized reviewer-facing materials for:

`Policy-Relevant Block Abstraction for Sequential Farmland Consolidation Scenario Screening`

It is intended for the anonymous code/reproducibility mirror associated with
Land Use Policy double-anonymized review.

## Included Materials

- `01_main_document_anonymous/`: anonymous manuscript source and PDF.
- `03_highlights/`: Elsevier-style highlights.
- `04_figure_captions/`: separate figure-caption file for Elsevier upload.
- `05_figures/`: high-resolution manuscript figure files.
- `06_latex_source_editable/`: editable anonymous LaTeX source plus required
  figures and table inputs.
- `07_declarations_and_checks/`: anonymized declarations and data/code
  availability text.
- `LUP_paper3_latex_source_anonymous.zip`: compressed anonymous source package.

## Excluded From This Repository Copy

Author-identifying title-page, cover-letter, declaration-of-interest form, and
author reference manuscript files are not included here because this directory
may be mirrored to an anonymous review repository.

## Review Copy Note

For double-anonymized review, provide the anonymous repository URL only in the
separate copy used for journal submission. This public repository copy
intentionally omits that URL to avoid linking the anonymous review mirror back
to the author-identifying repository.

The original TNLS cadastral parcel data are restricted and cannot be
redistributed. Included artifacts are derived or synthetic materials sufficient
to validate reported tables, figures, and code paths without exposing the raw
parcel geometry.
